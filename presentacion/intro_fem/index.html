¿Qué es el Método de Elementos Finitos?

Idea central

Un cuerpo continuo (viga, placa, sólido) se discretiza en N elementos finitos conectados por nodos.

En cada elemento se aproxima la solución con funciones de forma (Hermite, Lagrange, Q4, H8...).

Las ecuaciones del equilibrio se reducen a un sistema lineal:

\( \mathbf{K} \cdot \mathbf{u} = \mathbf{F} \)

Construcción

  1. Geometría → nodos + elementos
  2. Elemento → matriz local Klocal
  3. Transformación local → global TT·K·T
  4. Ensamblaje en sistema global
  5. Aplicar condiciones de borde
  6. Resolver K·u = F (LU, Cholesky, sparse)
  7. Calcular fuerzas internas Fint = K·u
El FEM es una técnica matemática rigurosa con casi 70 años de teoría establecida.

El ingeniero aporta CRITERIO

Lo que la máquina no puede hacer:

🎯 Modelar

  • ¿Frame, shell o sólido?
  • ¿Empotrado o pinned?
  • ¿Q4 thick (Mindlin) o thin (Kirchhoff)?
  • ¿Diafragma rígido?

📊 Cargar

  • D, L, E, W (NEC, ASCE 7)
  • Patrones, combinaciones
  • Sismo: estático/dinámico
  • Pushover (M-φ)

✅ Verificar

  • Convergencia de malla
  • Reacciones balanceadas
  • ASCE 7-22 §12.9.1 (90% MPF)
  • Análisis de sensibilidad
El software ejecuta. El ingeniero decide. Sin criterio, los resultados pueden ser numéricamente correctos pero físicamente absurdos.

El programador aporta BUCLES RÁPIDOS

El FEM resuelve sistemas con miles a millones de DOFs. La mano humana no escala. Los lenguajes científicos sí:

Fortran (1957)

El idioma original de la ciencia. Aún domina HPC, climate models, NASTRAN. Sintaxis austera, performance brutal.

C / C++ (1972 / 1985)

SAP2000, ETABS, ABAQUS, ANSYS, CalculiX, OpenSees: todos en C++. Control total de memoria, SIMD, threads.

Julia (2012)

Sintaxis matemática, velocidad de Fortran. Usado en MIT, Berkeley para nuevos solvers FEM (Gridap.jl, Ferrite.jl).

Python (1991)

Lenguaje "pegamento". OpenSeesPy, FEniCS, scikit-fem. Lento solo, RÁPIDO con NumPy/SciPy/JAX (que están en C/Fortran).

MATLAB (1984)

El estándar académico. Sintaxis matricial natural. Caro y closed-source, pero la base de muchos artículos FEM.

JavaScript / WebAssembly

Hekatan Struct: solver C++ → WASM → corre en navegador. Cero instalación.

No importa el lenguaje. Importa que ejecute K·u=F rápido y correctamente.

Hekatan Struct + Calcpad Symbolic

Dos herramientas complementarias:

🏗 Hekatan Struct

  • Solver C++ Eigen compilado a WASM
  • Modelado paramétrico por código (TypeScript)
  • Visor 3D Three.js, parametrizable con sliders
  • Round-trip .e2k ↔ ETABS
  • Open source MIT · GitHub Pages

→ Ejecuta el modelo y muestra el resultado FEM

📐 Calcpad Symbolic

  • Editor MATLAB-like con output simbólico KaTeX
  • Genera memoria de cálculo imprimible (fórmulas + valores)
  • Cada paso del FEM se escribe como ecuación
  • Integrado en Hekatan via panel 🧮 Calculadora FEM

→ Muestra la matemática paso a paso

Mismo modelo, dos lenguajes: el algorítmico (Hekatan) y el simbólico (Calcpad). Si producen el mismo número → la implementación es correcta.

Hekatan Lab — validación cruzada del solver
