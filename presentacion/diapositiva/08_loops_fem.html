Loops del FEM en acción

Cómo el computador suma las matrices locales en la matriz global $K$

El bucle fundamental

Toda la "magia" del FEM se reduce a este pseudocódigo:

K_global = zeros(N×N)              // matriz de ceros

para cada elemento e = 1, 2, ..., n_elementos:
    K_local = calcularKLocal(e)    // matriz pequeña (4×4 viga, 12×12 frame3D)

    para cada par (i, j) en K_local:
        I = índice_global(e, i)    // mapeo local → global
        J = índice_global(e, j)
        K_global[I, J] += K_local[i, j]   // ← SUMA, no asignación

resolver K_global · u = F

Eso es todo. La parte mágica es += — los nodos compartidos entre elementos suman sus contribuciones, igual que resortes en paralelo.

Lo mismo en MATLAB y C++

MATLAB / Octave
nElem = 4;
K_global = zeros(5, 5);

for e = 1:nElem
    Ke = beamK(E, I, L);
    % Mapeo local→global:
    %   nodo i del elem e → nodo e
    %   nodo j del elem e → nodo e+1
    K_global(e:e+1, e:e+1) = ...
        K_global(e:e+1, e:e+1) + Ke;
end

% Aplicar BC, resolver
K_red = K_global(2:end-1, 2:end-1);
u = K_red \ F_red;
C++ con Eigen
int nElem = 4;
Eigen::MatrixXd K_global =
    Eigen::MatrixXd::Zero(5, 5);

for (int e = 0; e < nElem; ++e) {
    auto Ke = beamK(E, I, L);
    // Mapeo local→global
    K_global.block<2,2>(e, e) +=
        Ke.block<2,2>(0, 0);
}

// Aplicar BC, resolver
auto K_red = K_global.block(1, 1, 3, 3);
auto u = K_red.lu().solve(F_red);

Por qué el loop es la verdadera "magia"

Una estructura de 100 elementos × matriz local 12×12 = 14,400 sumas. Una de 10,000 elementos × 12×12 = 1,440,000 sumas. A mano sería imposible — el computador lo hace en milisegundos.

Pero cada suma es trivial. Lo único que cambia entre Galerkin (1909) y Hekatan (2026) es:

  • Galerkin lo hizo a mano para problemas con 3-4 elementos.
  • Boeing 1956 lo programó en Fortran para 100 elementos — cambió la industria.
  • SAP/ETABS modernos hacen 100,000+ elementos en segundos — misma fórmula.
  • Hekatan lo hace en el navegador con WebAssembly — misma fórmula.
Conclusión: el loop es lo que diferencia el FEM "a mano" del FEM industrial. La matemática no cambió. Lo que cambió es la velocidad de ejecución. Por eso C++ → WebAssembly: ejecutar bucles a velocidad nativa, sin instalación.
