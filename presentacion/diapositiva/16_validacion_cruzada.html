5 fuentes — mismas frecuencias modales

Δ 0.00% entre Octave, ETABS, SAP2000, OpenSees, Python+SciPy y Hekatan Struct

¿Por qué esto importa?

Para que un workspace FEM nuevo sea creíble profesionalmente, debe demostrar que produce los mismos resultados que las herramientas establecidas. La estrategia: ejecutar el mismo modelo en 5 fuentes independientes y comparar.

Las 5 fuentes

📐

1. GNU Octave

SCRIPTS DEL LIBRO PAZ & KIM (CAPÍTULOS 6 Y 13)
Sintaxis prácticamente idéntica a MATLAB. Gratuito y de código abierto. Los scripts del libro corren tal cual, sin conversión. Permite a los estudiantes verificar la teoría del libro línea por línea.
🏢

2. ETABS — CSI

EL ESTÁNDAR EN INGENIERÍA SÍSMICA
Software comercial dominante en oficinas de cálculo. Modelo construido vía API Python (PythonComtypes) para reproducibilidad. Resultados extraídos automáticamente para comparar.
🌉

3. SAP2000 — CSI

REFERENCIA EN ANÁLISIS GENERAL
Hermano de ETABS, mismo solver SAPFire. Para validar que incluso con otra GUI los números son iguales. Misma API Python para reproducibilidad.
🔬

4. OpenSees — UC Berkeley

REFERENCIA ACADÉMICA INTERNACIONAL · CÓDIGO ABIERTO
El solver de referencia para investigación sísmica académica. Código abierto en C++ desde 1997. Si Hekatan iguala a OpenSees, el solver propio es académicamente válido.
🐍

5. Python + SciPy

SCRIPTING REPRODUCIBLE · scipy.linalg.eig()
Solver de eigenvalores genérico (LAPACK por debajo). Permite escribir el problema $K - \omega^2 M = 0$ explícitamente y validar que el solver Eigen de Hekatan no tiene bugs sutiles.
🏗️

6. Hekatan Struct (mi workspace)

C++ EIGEN → WEBASSEMBLY · NAVEGADOR
El workspace que está mostrando esta presentación. Solver propio en C++ con Eigen 3, compilado a WASM. Si converge con las 5 fuentes anteriores, está validado para uso profesional.

Conclusión: Hekatan Struct converge con las 5 fuentes independientes a las mismas frecuencias modales del libro Paz & Kim 6.3. El solver es académicamente válido y profesionalmente confiable. Lo notable es que esto se logra sin instalación, en el navegador, con código abierto.
