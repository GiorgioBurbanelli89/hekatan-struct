Análisis estático y dinámico — qué hace Hekatan hoy

Capacidades reales del solver C++ embebido. Lo que ya está, no lo que prometemos.

Análisis estático lineal

Resuelve el sistema $\mathbf{K}\,\mathbf{u} = \mathbf{F}$ ensamblado a partir de los $K_e$ derivados en el Bloque 2. Usa Eigen SparseLU con factorización LU dispersa.

API · DEFORM

Cálculo de desplazamientos y reacciones

import { deform } from "hekatan-fem";

const out = deform(
  nodes,           // [[x,y,z], ...]
  elements,        // [[i,j], [i,j,k,l], ...]  frames + Q4 + H8
  nodeInputs,      // { supports, loads, moments }
  elementInputs,   // { elasticities, areas, momentsOfInertia*, sectionShapes, ... }
  springsList,     // optional Winkler springs [{node, dof, k}]
);

out.deformations  // Map<node, [u,v,w,rx,ry,rz]>
out.reactions     // Map<node, [Fx,Fy,Fz,Mx,My,Mz]>
API · ANALYZE

Fuerzas internas y resultados de elemento

import { analyze } from "hekatan-fem";

const res = analyze(nodes, elements, elementInputs, deformOutputs);

// Frames (line elements):
res.normal       // N axial por elemento
res.shearY/Z     // V2, V3
res.torsion      // T
res.bendingY/Z   // M2, M3 a lo largo de la longitud (3 puntos)

// Shells (Q4 elements):
res.bendingXX/YY/XY     // momentos de placa por nodo
res.membraneXX/YY/XY    // tensiones de membrana
res.shellShearXY        // corte transversal
res.vonMises            // tensión equivalente

Tiempo típico: ~10 ms para 1 000 DOFs. ~1 s para 100 000 DOFs (edificio aporticado completo).

Análisis dinámico modal

Resuelve el problema de autovalores generalizado $(\mathbf{K} - \omega^2\,\mathbf{M})\,\boldsymbol{\phi} = \mathbf{0}$ con Eigen + Spectra (Lanczos para eigenvalores extremos en sparse).

API · MODAL

Frecuencias, formas modales y masa participante

import { modalAnalysis } from "hekatan-fem";

const m = modalAnalysis(nodes, elements, nodeInputs, elementInputs, 12);

m.frequencies        // [f1, f2, ..., f12] en Hz, ordenadas ascendente
m.modeShapes         // [φ1, φ2, ...] cada φ es Map<node, [u,v,w,rx,ry,rz]>
m.massParticipation  // [{ ux, uy, uz, rx, ry, rz }, ...] en %
                     //   por modo, en cada dirección global

Análisis dinámico time-history (Newmark-β)

Para los benchmarks Paz 4.1, 6.1, 8.1, 10.7 — integración temporal directa del sistema dinámico:

$$ \mathbf{M}\,\ddot{\mathbf{u}}_{n+1} + \mathbf{C}\,\dot{\mathbf{u}}_{n+1} + \mathbf{K}\,\mathbf{u}_{n+1} = \mathbf{F}(t_{n+1}) $$
API · TIME-HISTORY

Integración Newmark

import { newmarkBeta } from "hekatan-fem";

const th = newmarkBeta({
  K, M, C,                    // matrices ensambladas (sparse)
  forcing: (t) => F_at_t,     // función F(t)
  u0, v0, a0,                 // condiciones iniciales
  dt: 0.01, tEnd: 5.0,
  beta: 0.25, gamma: 0.5,    // promedio constante (incondicionalmente estable)
});

th.timeArray            // [0, dt, 2dt, ...]
th.displacementSeries   // u(t)
th.velocitySeries       // ̇u(t)
th.accelerationSeries   // ̈u(t)
