CAPA 3 · SOLVER C++

⚙️ hekatan-fem (Eigen 3 + C++17)

El núcleo numérico: ensambla $K$ global, aplica BC, factoriza con SparseLU, resuelve $K\,u = F$, calcula fuerzas internas. Mismas ecuaciones que ETABS, OpenSees, ABAQUS.
C++17 · Eigen 3 · BLAS
↓ compilado a WebAssembly
CAPA 4 · WASM

🌐 WebAssembly via Emscripten

El binario C++ se compila a .wasm: bytecode portable que el navegador ejecuta a velocidad nativa (~95% de C++ puro). Sin instalación, sin servidor.
Emscripten · embind · LLVM
↓ corre en el navegador

El "puente" Eigen ⟶ JavaScript

Cómo el solver C++ se expone al navegador (simplificado):

deform.cpp (C++)
#include <Eigen/Sparse>
#include <emscripten/bind.h>

DeformResult deform(
    const std::vector<Node>& nodes,
    const std::vector<Element>& elements,
    const NodeInputs& ni,
    const ElementInputs& ei) {
  // 1. Ensamblar K (sparse)
  Eigen::SparseMatrix<double> K(ndof, ndof);
  buildStiffness(K, nodes, elements, ei);
  // 2. Aplicar BC + cargas
  applyBC(K, F, ni);
  // 3. SparseLU solve
  Eigen::SparseLU solver;
  solver.compute(K);
  Eigen::VectorXd u = solver.solve(F);
  return { u };
}

// Exportar a WASM
EMSCRIPTEN_BINDINGS(hekatan_fem) {
  function("deform", &deform);
}
deform.ts (TypeScript)
import deformWasm from "./deform.wasm";

const Module = await deformWasm();
// Module.deform es la misma función C++

export function deform(
    nodes: Node[],
    elements: Element[],
    nodeInputs: NodeInputs,
    elementInputs: ElementInputs,
): DeformOutputs {
  // 1 línea — la magia ocurre en C++
  return Module.deform(
    nodes, elements,
    nodeInputs, elementInputs,
  );
}

// Uso en el ejemplo:
const out = deform(nodes, elems, ni, ei);
console.log(out.deformations);
