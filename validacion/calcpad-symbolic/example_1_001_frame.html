3. Convención de ejes locales CSi

Crítica para Patterns 5, 6, 7 (cargas en local axis 2):

  • axis 1 (ex) = a lo largo del miembro (i → j)
  • axis 2 (ey) = proyección de +Z global sobre plano perp a ex.

    Para columna vertical: ey = +X global.

  • axis 3 (ez) = ex × ey

Pattern 4 usa PROJECTED GRAVITY (CSi Dir=11): la carga q se

especifica por unidad de proyección HORIZONTAL. Para Frame 2 con

L_proj=8ft, L=10ft → ratio=0.8, q_actual=1.6 kip/ft.

 

4. Unidades — Modelo en kip-in

CSi Example 1-001 verbatim usa kip-ft (cargas) y kip-ft (momentos). Como el

modelo trabaja en INCHES, convertimos:

  • distribuida: kip/ft → kip/in (dividir por 12)
  • momento: kip-ft → kip-in (multiplicar por 12)
  • longitud: ft → in (multiplicar por 12)

8. Conclusión

Los 4 ports self-contained reproducen el oficial CSi Example 1-001 al <0.05% en los 7 load patterns, incluyendo casos no-triviales:

  • Pattern 1: self-weight con consistent fixed-end forces
  • Patterns 5, 6: cargas distribuidas en ejes LOCALES
  • Pattern 4: PROJECTED GRAVITY (escala por L_proj/L)
  • Pattern 7: carga puntual interior (mid-span)

Fixes clave aplicados al MATLAB original para alcanzar paridad CSi:

  1. Lumped equivalent → CONSISTENT fixed-end forces (con momentos qL²/12)
  2. Convención ejes locales: CSi (proj de +Z, +X si vertical) en vez de cross([0,0,1], ex)
  3. Unit conversions: kip/ft → kip/in (distribuidas /12, momentos *12)
  4. Pattern 3: aplicado en nodo 2 (knee), no en nodo 3 (top)
  5. Pattern 4: PROJECTED GRAVITY con escala L_proj/L
